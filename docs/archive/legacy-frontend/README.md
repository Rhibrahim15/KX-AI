# Archived duplicate frontend scaffold

This directory preserves the separate `frontend/` Next.js create-app scaffold that existed beside the actual root Next.js application (`src/`).

It was not the canonical product UI or deployment target. The active web app is the root application, with its server-side chat BFF at `src/app/api/chat/route.ts`.

The scaffold was moved here intact to eliminate the duplicate app and avoid uncertainty over which frontend should be built or deployed. It is historical reference only.
